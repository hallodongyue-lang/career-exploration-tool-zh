## 📌 项目简介

本项目是一款面向职业探索与求职方向选择的交互式问卷工具。

通过情境式问题收集用户的学科背景、职业兴趣及工作偏好，并生成多维度职业画像、行业方向与岗位推荐，为个人职业探索提供结构化参考。

项目采用 HTML、CSS 和 JavaScript 实现，支持浏览器直接访问及离线运行。

## ✨ 核心功能

### 1. 40道情境式探索题目

问卷共包含40道题：

- 2道学科路线题
- 6道职业兴趣题
- 32道独立工作偏好题

### 2. 多维度职业画像

根据用户的选择，生成：

- 彩色职业兴趣画像
- 八维工作偏好分析
- 详细求职者画像

### 3. 行业与岗位推荐

结合问卷结果，通过预设规则生成行业与岗位推荐，为用户提供职业探索参考。

### 4. 本地计算与隐私保护

- 无需注册或登录
- 用户答案仅在当前页面计算
- 不上传、不保存问卷答案
- 刷新或关闭页面后需重新填写

## 🌍 English Overview

**Career & Personality Exploration** is an interactive, browser-based career exploration tool developed with AI-assisted coding.

The questionnaire consists of 40 questions:

- 2 academic pathway questions
- 6 career interest questions
- 32 independent work preference questions

Based on user responses, the application provides:

- Visual career interest profiles
- Eight-dimensional work preference analysis
- Industry and job recommendations
- Detailed career exploration profiles

The application is built with HTML, CSS, and JavaScript.

All questionnaire responses are processed locally in the browser. Answers are neither uploaded nor stored.

**Disclaimer:** This is an independently developed exploratory tool. It has not undergone standardized psychometric validation and should not be considered a professional personality assessment or employment guarantee.
